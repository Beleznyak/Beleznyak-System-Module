# Мобильное приложение для визуализации аналитических метрик

## Назначение модуля в общей системе
Данный модуль представляет собой клиентскую часть (мобильное приложение) корпоративного помощника. Приложение обеспечивает интерфейс для взаимодействия пользователя с аналитической системой, визуализирует метрики, позволяет просматривать документы, общаться в чате поддержки и настраивать профиль (включая биометрию и темную тему).

## Используемый стек технологий
* **Frontend/Mobile**: Flutter / Dart (или React Native) — для кроссплатформенной разработки мобильного приложения.
* **State Management**: BLoC / Provider — для управления состояниями экранов.
* **Локальное хранилище**: Hive / SQLite — для кеширования документов и сохранения настроек (темная тема, биометрия).
* **Сеть**: Dio / HTTP — для отправки запросов к серверу по REST API и WebSockets (для чата).
